# Люся — голосовой ассистент для Windows

Пиксельная героиня, которая живёт внизу экрана, сама занимается своими делами
(спит, читает, гуляет, ест, готовит, танцует под музыку) и выполняет голосовые
команды после обращения по имени: «Люся, открой браузер».

## Установка

1. Python 3.11+, Windows 10/11.
2. Зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Русская модель распознавания речи Vosk (офлайн, ~45 МБ):
   скачать [vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip)
   и распаковать в папку `models/`, чтобы получилось `models/vosk-model-small-ru-0.22/`.

## Запуск

```
python main.py            # окно с героиней и голосом
python main.py --console  # текстовый режим в консоли
```

## Команды

Сначала имя — «Люся» (или «Люська», «Люсь»), после сигнала — команда:

| Что | Примеры |
|---|---|
| Программы | открой/закрой браузер, открой дискорд, открой ютуб, твич |
| Музыка (Яндекс.Музыка) | включи музыку, пауза, играй, следующий трек, предыдущий |
| Громкость | громче, тише, выключи звук |
| Прочее | помощь, выключи ассистента |

Мышью: клик — поле для текстовой команды, перетаскивание — переставить, правая кнопка — меню.

## Настройка

Всё в `config.json`: программы и их названия, сайты, слова-обращения,
размер героини (`sprite_scale`), микрофон (`raw_microphone`).
При запуске конфиг проверяется; если в нём ошибка — Люся покажет, что и где не так.

**Приватность.** В журнал `logs/voice.log` по умолчанию пишутся только технические
события (микрофон, громкость, «услышала имя»), но не сами фразы. Для отладки
распознавания можно включить `"debug_speech_log": true` — тогда фразы пишутся
в журнал, и Люся предупреждает об этом при запуске.

**Закрытие программ.** «Закрой …» закрывает только видимые окна программы — как
нажатие на крестик, так что несохранённые данные программа спросит сама.
Принудительно завершаются лишь программы с `"force_close": true` в конфиге.

## Файлы

| Файл | Что делает |
|---|---|
| `main.py` | запуск |
| `gui.py` | окно, поведение и анимации героини, реплики |
| `sprites.py` | пиксельная отрисовка героини |
| `listener.py` | голос: ожидание имени и команды (Vosk) |
| `commands.py` | разбор фразы в команду |
| `executor.py` | выполнение команд |
| `media.py` | управление плеерами через медиасессии Windows |
| `system.py` | медиаклавиши, громкость, закрытие программ |
| `sounds.py` | короткие звуковые сигналы |
| `config.py`, `config.json` | настройки |
