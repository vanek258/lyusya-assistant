# Люся — голосовой ассистент для Windows

Пиксельная героиня, которая живёт внизу экрана, сама занимается своими делами
(спит, читает, гуляет, ест, готовит, танцует под музыку) и выполняет голосовые
команды после обращения по имени: «Люся, открой браузер».

## Установка

1. Python 3.11+, Windows 10/11.
2. Зависимости:
   ```
   pip install -r requirements.txt
   ```
3. Русская модель распознавания речи Vosk (офлайн, ~45 МБ):
   скачать [vosk-model-small-ru-0.22](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip)
   и распаковать в папку `models/`, чтобы получилось `models/vosk-model-small-ru-0.22/`.

## Запуск

```
python main.py            # окно с героиней и голосом
python main.py --console  # текстовый режим в консоли
```

## Команды

Сначала имя — «Люся» (или «Люська», «Люсь»), после сигнала — команда:

| Что | Примеры |
|---|---|
| Программы | открой/закрой браузер, открой дискорд, открой ютуб, твич |
| Музыка (Яндекс.Музыка) | включи музыку, пауза, играй, следующий трек, предыдущий |
| Громкость | громче, тише, выключи звук |
| Прочее | помощь, выключи ассистента |

Мышью: клик — поле для текстовой команды, перетаскивание — переставить, правая кнопка — меню.

## Настройка

Всё в `config.json`: программы и их названия, сайты, слова-обращения,
размер героини (`sprite_scale`), микрофон (`raw_microphone`).
При запуске конфиг проверяется; если в нём ошибка — Люся покажет, что и где не так.

**Приватность.** В журнал `logs/voice.log` по умолчанию пишутся только технические
события (микрофон, громкость, «услышала имя»), но не сами фразы. Для отладки
распознавания можно включить `"debug_speech_log": true` — тогда фразы пишутся
в журнал, и Люся предупреждает об этом при запуске.

**Закрытие программ.** «Закрой …» закрывает только видимые окна программы — как
нажатие на крестик, так что несохранённые данные программа спросит сама.
Принудительно завершаются лишь программы с `"force_close": true` в конфиге.

**ИИ и облако.** По умолчанию выключено: без раздела `cloud` в `config.json`
ни одна фраза не уходит в интернет, а на неизвестную фразу Люся отвечает
«Этого я пока не умею». Настройки (все необязательные):

```json
"cloud": {
  "enabled": false,
  "allow_fallback": false,
  "max_words": 25,
  "min_confidence": 0.75,
  "daily_request_limit": 200
}
```

API-ключи **никогда** не пишутся в `config.json` (Люся откажется запускаться,
если найдёт там параметр вроде `api_key`). Ключ сохраняется в Диспетчере
учётных данных Windows: команда открывает окошко с кнопкой «Вставить из буфера».
Ключ вписывается в окошко, **не** в саму команду:

```
python secret_store.py set gemini_api_key
python scripts/check_gemini.py     # проверить ключ и доступ к Gemini API
```

Архитектура и порядок разработки — в [docs/MIGRATION_PLAN.md](docs/MIGRATION_PLAN.md).

## Состояние проекта

| Этап | Статус |
|---|---|
| 1. Стабилизация (приватность журнала, остановка, ошибки, тесты) | ✅ готов, метка `stage1-checkpoint` |
| 2. Архитектура: ядро диалога, маршрутизация, инструменты с рисками, интерфейс ИИ, ключи, память | ✅ готов, метка `stage2-complete` |
| 3. Gemini: проверка API | ✅ ключ, модели, ответ на русском и ошибки проверены (`scripts/check_gemini.py`) |
| 3. Gemini: подключение к Люсе (`GeminiProvider`) | ⏳ следующий шаг |
| 4–8. Голосовые ответы, память, расширения | запланировано |

**Известные открытые вопросы:**
- длинный текст обрезается сверху облачка — нужна прокрутка по страницам до подключения ИИ;
- изредка теряется первая команда после запуска (видно в тестах через динамики ноутбука, на живом голосе не проверено);
- дневной лимит запросов к ИИ считается в памяти и сбрасывается при перезапуске.

## Файлы

| Файл | Что делает |
|---|---|
| `main.py` | запуск и сборка компонентов; защита от второго экземпляра |
| `gui.py` | окно: героиня, анимации, облачко — только отображение |
| `sprites.py` | пиксельная отрисовка героини |
| `listener.py` | голос: ожидание имени и команды (Vosk), уверенность распознавания |
| `dialogue.py` | ядро диалога: фраза → решение → действие или ИИ → ответ |
| `events.py` | сообщения между ядром и окном |
| `intent_router.py` | локально / в ИИ / переспросить / пропустить |
| `tools.py` | каталог действий Windows, белые списки, уровни риска, подтверждение |
| `commands.py` | разбор фразы в команду |
| `executor.py` | выполнение команд |
| `ai/` | интерфейс ИИ-провайдера, выбор провайдера (`AIRouter`), поддельный провайдер для тестов |
| `memory.py` | краткосрочная память разговора |
| `persona.py` | личность Люси — одна для любой модели |
| `secret_store.py` | API-ключи в Диспетчере учётных данных Windows |
| `media.py` | управление плеерами через медиасессии Windows |
| `system.py` | медиаклавиши, громкость, окна и процессы |
| `sounds.py` | короткие звуковые сигналы |
| `config.py`, `config.json` | настройки и их проверка |
| `scripts/check_gemini.py` | изолированная проверка Gemini API |
| `docs/MIGRATION_PLAN.md` | согласованный план архитектуры |
